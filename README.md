# 💫 心語星球

> 一個結合社群、即時聊天與 AI 陪伴的溫暖平台

## ✨ 功能介紹

- 🔐 **會員系統**
  - 使用者可登入 / 登出，建立個人帳號與資料。

- 🌍 **探索其他人**
  - 查看他人的貼文與限時動態，發現更多故事。

- 🤝 **好友功能**
  - 可送出好友邀請，建立彼此連結。

- 💬 **即時聊天**
  - 好友之間可進行即時一對一聊天。

- 💰 **線上儲值**
  - 支援金幣儲值，解鎖更多互動與功能。

- 🎁 **每日小天使推薦**
  - 每日推薦 1 位「小天使」。
  - 照片模糊顯示，雙方同意加好友並花費金幣後即可揭曉真面目。

- 🤖 **AI 陪伴聊天**
  - 提供 AI 陪聊機器人，隨時傾聽並陪伴你。
